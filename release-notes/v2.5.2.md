## pyTOP Pro v2.5.2 — Sunucu bölümü

### ✨ Yenilikler

**Sunucu (pyTOP Server)** — kenar çubuğunun **Çalışma alanı** kısmında yeni bölüm.

- **Bu makine:** Uzak erişimin açık olup olmadığı, dinleme adresi ve portu, erişim tokeninin ayarlı olup olmadığı ve çalışma şekli (systemd servisi / uygulama içi). Token hiçbir yerde gösterilmez.
- **Bağlantı adresleri:** Diğer cihazların bağlanacağı `http://IP:PORT` adresleri, tek tıkla kopyalanabilir. Uzak erişim kapalıysa nasıl açılacağı yazar.
- **Kayıtlı sunucular:** Uzak pyTOP Server profillerini ekleyin, **Bağlan** ile paneli bu pencerede açın veya silin (masaüstü uygulaması).
- **Linux sunucusuna kur:** Kurulum, token görüntüleme ve günlük komutları adım adım, kopyalanabilir.

### 🔧 Diğer

- README v2.5 yenilikleriyle güncellendi (Sistem Haritası, Grafit Gri tema, Sunucu bölümü).

### 📦 İndirme

| Platform | Dosya |
| --- | --- |
| Windows 10/11 (x64) | `pyTOP-Pro-Setup-2.5.2.exe` |
| Linux (x86_64, her dağıtım) | `pyTOP-Pro-2.5.2-Linux-x86_64.AppImage` |
| Debian / Ubuntu | `pyTOP-Pro-2.5.2-Linux-amd64.deb` |
| Linux sunucu (pyTOP Server) | `install-server.sh` |

Paketler Python kurulumu gerektirmez.

### 🔄 Otomatik güncelleme

Windows kurulumu ve Linux AppImage sürümü bu güncellemeyi uygulama içinden otomatik olarak alır. `.deb` paketini kullananlar yeni sürümü bu sayfadan indirip kurabilir.
