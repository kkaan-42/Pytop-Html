## pyTOP Pro v2.5.1 — Grafit Gri tema

### ✨ Yenilikler

**Grafit Gri** — yeni varsayılan tema.

- Kenar çubuğu, üst çubuk, özet kartları, donanım panelleri, süreç tablosu ve Canlı Sistem Haritası nötr gri tonlarda.
- Renk yalnızca durum anlatır: yüksek yük **amber**, kritik yük **kırmızı**, çevrimiçi göstergeleri **yeşil**. Sorunlu değerler gri zeminde hemen göze çarpar.
- Ağ grafiğinde indirme açık gri, yükleme kesikli çizgiyle gösterilir.
- Sistem Haritası'ndaki düğüm ve yol renkleri seçili temaya uyar.

### 🎨 Tema seçimi

- Daha önce tema seçmemiş kullanıcılar uygulamayı Grafit Gri ile açar.
- Kaydedilmiş tema tercihiniz korunur. Btop Slate, Htop Classic, Monokai ve Matrix Green temaları değişmeden duruyor; **THEME** menüsünden veya **F2** ile geçiş yapabilirsiniz.

### 📦 İndirme

| Platform | Dosya |
| --- | --- |
| Windows 10/11 (x64) | `pyTOP-Pro-Setup-2.5.1.exe` |
| Linux (x86_64, her dağıtım) | `pyTOP-Pro-2.5.1-Linux-x86_64.AppImage` |
| Debian / Ubuntu | `pyTOP-Pro-2.5.1-Linux-amd64.deb` |
| Linux sunucu (pyTOP Server) | `install-server.sh` |

Paketler Python kurulumu gerektirmez.

### 🔄 Otomatik güncelleme

Windows kurulumu ve Linux AppImage sürümü bu güncellemeyi uygulama içinden otomatik olarak alır. `.deb` paketini kullananlar yeni sürümü bu sayfadan indirip kurabilir.
